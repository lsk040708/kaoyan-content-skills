# 考研文案生成器

## 承接选题

有选题生成器的结果时，沿用用户选定的题和已有的目标观众、具体卡点、正文承诺及可展示材料。先把承诺写成一句内部验收标准，例如“看完能给两个备选各写一个接下来要查的问题”，再把方案写成观众听得懂的话。用户只给题目时直接补足这些信息。需要批量选题时使用 `generate-kaoyan-topics`。

## 动笔前在内部确定四件事

1. **说给谁听**。沿用已确定的受众、考研届次和创作者身份。只有题目时，从题目推断观众所处的具体阶段和任务，用自然的第二人称写作。不默认届次，不自动给作者加上岸经历、学历或带学身份。
2. **观众卡在哪**。把题目落在一个能听懂的场景，例如已经收藏好几所学校，却不知道先查哪所。
3. **这一条实际回答什么**。沿用选定主题和选题卡已有的内容承诺，缩到一个能说清的判断或动作。例如给两个择校候选各标一个下一步，而不是讲完整择校流程。把“看完能做什么”当作写完后的验收标准。
4. **靠什么兑现**。从已有素材选一个真正用得上的内容，优先用用户能展示的真实场景或操作、公开官方文件，或明确以“假设”“比如你手上有……”引入的示例。材料足够就直接写。只有关键歧义会改变交付时，才问一个具体问题。

## 从参考作品转成自己的口播

有参考链接时，先核对作者和单条作品，按实际能看到的范围辨认开场、正文每段怎样给理由、末尾怎样收住。将封面字、发布配文、观众评论、视频内字幕或口播分别辨认。只取得标题、片段或自动转写时，借鉴相应部分的结构，并在用户要求拆解时交代取样范围。带数据的样本用于选择表达方式，内容结论使用独立证据。写院校清单、资料选择，或用户点名胡跳跳学姐时，参考 [四条抖音样本与文案写法](douyin-samples.md)。

- **观众正在犹豫**。用一句真实场景或明确标成假设的提问开场，亮出判断条件，再用一个取舍讲透。真评论可匿名用来点题。虚构情境用“假如你……”引入。
- **候选名单或对比**。先说清适用人群与入选条件，再逐项讲“这个选项适合谁、依据在哪一条、接下来核实什么”。条数服从可核实的材料和时长。遇到医学择校，按对应年份核对本科专业或学历背景、报考院系和专业代码，并区分学硕与专硕。评论里的说法只作待查线索。若只有名单或传闻，给适用条件和查证步骤。分镜同时核对口播、字幕、院校全称、院系及校徽归属。
- **资料搭配或实操**。按观众真正要完成的任务拆到能说清的几段，展示一份材料的实际用法或一个动作的结果。写观点题时可以用情境与判断推进，画面随实际讲法设计。

把上述写法用到用户自己的问题、依据与例子上。用原创措辞形成自己的开场和理由，学校、书单、经历和咨询引导均按用户当前素材重新核实。开场给出的承诺要在正文中交付，结尾的问题或行动承接同一个决定。

## 写成能念的稿

- 开头直接进入具体困境，让观众听得出这是在说自己的哪件事。省去问候、空泛预告和虚构的“很多学生问我”。
- 中段围绕一个判断推进，用一个具体例子或动作解释怎么做、凭什么判断。用短句、自然转折和停顿，读起来像在和学生聊天。把正文读一遍，按自然语速粗估45～60秒，优先删掉重复铺垫。
- 结尾只留一个正文已经铺垫过、观众现在就能做的动作。当前新账号没有付费课、学员案例或资料包。以用户后续明确提供的真实情况为准，禁止虚构学员经历、提分结果、上岸保证、可领取资料，禁止靠制造焦虑逼互动。

具体院校政策、人数、日期、考试科目等说法，先查招生单位官网、对应院系或研招网的官方原文，核对招生年份、适用院系或专业、适用人群及口径。历史材料只作对应年度参考。口播采用已核实事实时，可在正文后简列官方来源和适用范围。未来信息尚未公布或无法核实时，删掉未核实的具体断言，把内容落到真实可示范的查询、对照或填写方法上。

## 按用户指定的形态交付

- 默认只输出一版简体中文口播正文。只写视频里要说的话，保留必要的自然分段。内部的人群、卡点、内容承诺及选题判断无需展示。用户明确只要正文时，用无需外置来源即可成立的内容完成。
- 抖音发布配文写作品下方供观众阅读的正文。用简短文字补充观看语境或保留一个自然互动点。
- 封面标题写画面上快速可读的引导语，保留同一个内容承诺。
- 改稿保留主题、原意、创作者身份及用户认可的句子。优先调整绕口、重复或兑现不足的段落。若必须改动用户认可但含有未证实断言的句子，保留原观点并改用有依据的表达。
- 补分镜时，将口播和画面分栏，以已有口播为准，逐段匹配能拍到的动作、表格、屏幕录制或官方文件。口播栏只放需念的话，画面栏只写观众看到的内容。画面应帮助看清方法，例如说“给两所学校标下一步”时，实际展示两行表格及其标记。
- 用户点名一种形态时，只交对应内容。只有明确要求组合时，才交多种形态。
