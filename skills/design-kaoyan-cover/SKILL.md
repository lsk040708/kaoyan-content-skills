# 考研短视频封面

沿用已定选题和口播。先决定观众扫一眼应该看到什么，再挑画面和排字。只改标题文字时，可承接 `write-kaoyan-copy`。题目还没有定时，先用 `generate-kaoyan-topics` 核对人群和正文交付。

## 先从内容里定封面

1. 写下谁会停下来、他此刻要做哪一个判断，以及视频确实给了他什么。把这些信息压成一个视觉主标题。先试一至两行，长校名或专业名可按可读性换行。主标题让观众看清是讲哪件事，副标题用于补人群、条件或动作。
2. 判断该用哪种画面。选定一项主要视觉线索，试过手机缩略图再加小字或第二张资料。
3. 封面主标题、发布标题和视频第一句各自写一遍。三者围绕同一个问题，封面保留最快能懂的信息。封面有数字时核对正文的数量和统计口径，写院校或政策时按官方资料核对年份和适用对象。

| 这条在讲什么 | 先试什么画面 |
|---|---|
| 双非择校、择校对比 | 把人群或问题提到大字，加一张真实院校卡、报名条件或比较表，让它与口播指向同一所院校和专业。 |
| 某专业的具体追问 | 出镜画面配一条与本片相符的真实提问，必要时处理头像和账号信息。没有现成提问时用本片自己的问题做标题。 |
| 报考入口、政策流程 | 最大字写入口或要完成的事。只截可读的官网标题、字段或按钮，保留使用必要的出处。 |
| 备考复盘、个人决策 | 先把处境和选择说清楚，人像用本人的自然表情或动作。有数字清单时让数字与实际正文匹配。 |

研究参考 IP 时，从主页作品卡确认原封面，核对作者和原链接。记录第一眼读到的词、人像比例、上中下的位置、颜色、素材卡有无，以及缩小时会丢掉什么。需要考研案例时读[胡跳跳学姐考研六张主页封面](references/hu-tiaotiao-covers.md)。互动排名可用于挑样本。要评估封面效果，查看封面的展示和点击数据，或做相近条件下的封面对比。

## 排版和交付

- 优先挑用户自己的出镜帧，眼神清楚、表情自然，给主标题留出空间。无需出镜的内容可用公开资料截图、自己做的表格或授权素材。展示院校信息时核对校名、校徽、院系与年份。用原创措辞和自己的素材搭配参考中可复用的层级。
- 让主标题最大。副标题少一档，资料卡再小一档。底图起伏大时，用能看清的描边、局部底色或留白。默认选一个重点色来标核心词，缩小后仍能一眼看见。角标按用户要求加。
- 按用户或发布场景要求定比例。未指定比例时，定稿默认交付 **3:4 竖版**和 **4:3 横版**。竖版可上下排标题和人像，横版可左右分栏。重新检查两个比例的标题、人脸和证据卡位置。
- 只有稿件或缺少关键素材时可先交封面文字和排版预览，在预览里清楚标示待替换画面。已有素材就直接做封面预览。用户要求保存时导出需要的比例，用清楚的文件名区分版本。

## 手机端检查

把封面缩到约 160 像素宽，或放到同批作品缩略图旁边。检查是否能说出它在讲谁的什么事。再看主标题是否被边缘或平台控件遮挡，人脸是否被压住，资料卡是否还能认出。逐字核对届次、数字、院校、专业以及视频实际承诺。人物、资料图和导出的原创封面使用无来源水印的版本。
