# 考研短视频剪辑

从用户定稿和实录出发。先确定观众在这一条里要辨认哪所学校、看懂哪个条件，或完成哪一步操作。没定题时接 `generate-kaoyan-topics`；需要写稿或修正口播时接 `write-kaoyan-copy`。有定稿就直接进剪辑，事实修正与重录单独标给用户。

## 按已有素材开工

- **只有文稿**：交付可拍可剪的分镜，逐段列出原文、预估时长、主画面、字幕强调和资料出处。拿到录音后以实际时间重排。
- **有真人素材或录音**：先接好口播，再定画面。结合识别结果、波形和画面，保留最后一次完整流畅的重读，去掉废句和过长的空拍，保留句间呼吸。剪同机位口播时，发现跳切过明显，可让该句重新录制，或用这句本来就需要的资料画面承接。用最终音轨校正字幕，检查开头、中段、结尾的音画对齐。
- **给了参考链接**：核对单条原片，记录所见画面和能核实的音频。找片头、信息换项、资料出现和结尾几个位置。需要看可迁移的做法时，读[三条样片的时间点](references/douyin-editing-samples.md)。用自己的出镜、排版和素材重新制作。

## 用口播决定画面

1. **开头先让观众知道自己为什么要看。** 给出人群、具体问题或利益点，接着进入第一项或第一步。原片开头约 3 秒进入正题，可用来检查自己是否铺垫太久。时长服从内容和说话速度。
2. **学校清单或对比**：让人像担当主画面。每换一所，在第一次念出校名时换同位置的校名卡或校徽，讲理由期间让它留在画面上。校名、结论和数字用同一种强调色。政策或数字是核心判断时，给到可读的官方材料，并注明适用年份、院系或专业。名单长时，优先保留观众能用来判断的项。
3. **网站实操**：用人像交代问题和操作目的，讲到动作时切到对应网页或把网页叠到画面上。按“入口 → 点击位置 → 结果”组织素材，每个框或指示只对准当前讲的地方。把关键行放大到手机能看清，停留到观众读完。需要解释条件时回到人像，下一步再切资料。网页和步骤以录制时的官方页面为准。
4. **单问题判断**：先用人像讲清判断条件，再用一张真实岗位表、专业目录或招生章程举例。只圈出支撑口播的格子或原文，画面最后回到观众可以采取的一个动作。这类口播可直接参考[中医学大四的分镜](references/storyboard-example.md)。

## 字幕、画幅和交付

- 用短句块跟口播切字幕。可从一行白字配深色描边开始，专名、入口或关键数值给一个强调色。网页叠上来以后，给字幕和需要看清的内容各留空间。用手机尺寸预览，检查平台控件可能覆盖的位置。
- 用项目或用户指定的画幅。按这三条样片做竖版构图时，可参考原片 3:4；若交付 9:16，重新安排人像裁切、证据画面和字幕位置。默认使用无来源水印的自有或获准素材，角标按用户要求添加。
- 人声清晰优先。音乐和音效按项目需要选用，试听叠加处，确保学校名、条件和点击动作都能听清。对照最终音轨核对字幕错字、吞字、遮挡、切点和画面所指对象。校徽、院校全称、截图年份与口播逐项对齐，证据中的口径与口播一致。
- 已有素材时交可修改的剪辑工程或时间轴、同步字幕和可播放粗剪预览。默认沿用用户已选工具；没有现成工程时可用 Remotion Studio 预览，明确要求保存时再导出。发现片段时长与文稿估计不同，报告试听后的实际时长。
