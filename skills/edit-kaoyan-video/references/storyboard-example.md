# 分镜示例｜中医学大四，想去杭州当医生

适合已定稿的单问题口播。拿到录音后按实际语句对齐切点。

| 口播节点 | 画面与剪点 | 屏幕重点 |
|---|---|---|
| 中医学大四，毕业想去杭州当医生，考研还是先工作 | 人像直接开口。说出职业目标时给简短标题 | 杭州当医生 |
| 实习时哪个科室最愿意待 | 继续人像，用针灸推拿做例子，念到招聘公告时切资料 | 先找目标科室 |
| 翻招聘公告，核对学历、执医资格、住培 | 放大官方岗位表的一行。随着口播依次框住学历、执医资格、住培要求；有同等待遇条款时切到公告对应段落 | 目标岗位的真实条件 |
| 分别说清先考专硕、先工作的条件 | 回到人像，每个条件出现时用一行字幕。用户已核实岗位或培养条件时，可在对应语句短暂插一张材料 | 专硕衔接住培／临床带教 |
| 今天找一张真想投的岗位表 | 用干净的示例行圈出还差的一项，到行动句结束 | 圈出还差的条件 |

带具体岗位要求的镜头使用招聘方发布的附件。可从[浙江省人社厅的历史招聘公告及岗位表](https://rlsbt.zj.gov.cn/col/col1229743683/art/2025/art_d507f00da24d4d3c9b1103f0167dbd1a.html)找适合演示的样例，并保留公告年份。没有素材时可做标明“示意”的空白表格，等核实原件后再录具体表述。
